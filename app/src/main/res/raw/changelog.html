2.0.25

- Homework text can now be copied: a copy button on every homework card and in the lesson detail, and all lesson-detail text is selectable.
- Fixed the current-lesson highlight getting stuck on a lesson that was already over - it now moves on by itself.
- Fixed weeks getting mixed up when the app was left open across midnight or across the "switch to the next week" moment.
- New themes: Nord, Dracula, Solarized Light and Catppuccin Latte.
- Website and Report an issue now point at this fork's GitHub page instead of the original author's.
- The combined Homework tab now clearly separates school homework from your own tasks.
- New optional Compact next lesson card (Settings → Timetable): two lines instead of three, with the weekday shown when the lesson is not today. The original three-line card stays the default.
- Timetable columns are now all the same width, and the hour column no longer takes up as much room as a whole school day.
- Both cards now sit evenly clear of the timetable and the info line — the card used to be glued to the grid with a gap only underneath it.
- The countdown now matches how far away the lesson is — starts in 2 days rather than 1d 21h 6m 46s. Seconds only appear in the final minute, and the card stops redrawing once a second when nothing on it changes that fast.
- The info line now uses the text size defined by your theme; it had been ignoring it and rendering at the default size.
- The transpose button no longer glows orange — its arrows now turn to match the axis of the table.
- Removed the Transposed table, Alternating rows and Alternating columns settings. Transposing itself stays - use the toggle button in the timetable toolbar.

- Lesson-detail dialog restyled so the useful info stands out more.
